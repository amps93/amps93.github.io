4검색을 위해 문서 단위와 청크 단위로 색인을 분리했습니다. document_index에는 문서 요약과 메타데이터를, segment_index에는 본문 청크를 저장해 문서의 전체 내용과 세부 내용을 각각 검색할 수 있도록 했습니다.

AI 문서 처리 설계

  • PDF·HWP의 텍스트 추출 경로를 구성하고, 이미지 기반 문서는 PaddleOCR-VL로 변환
  • 문장·문단 경계를 반영해 청킹하고 짧은 청크를 병합해 모델과 검색에 사용할 입력 단위를 구성
  • 요약·키워드 생성 시 인물·기관·정책·사건명을 유지하도록 프롬프트를 설계
  • BGE-M3 임베딩과 개체명 추출 결과를 문서·청크 색인 단계에 연결
  • OCR·LLM·임베딩 서비스를 분리해 모델별 실행 환경과 확장 단위를 관리

부가 모델

Item2Vec 연관기사 추천

2022.12 – 2023.01 · 평가 2023.11추천

기존 연관기사 알고리즘(TF-IDF·연관규칙)과 겹치지 않는 신호를 얻기 위해, 기사 텍스트 대신 클릭 순서 자체를 학습하는 Item2Vec 추천을 설계·구현했습니다. 로그 종류와 파라미터를 실험으로 정하고, 30분 배치에 학습·추론을 넣어 운영했습니다.

문제와 제약

  • 사용자 로그에 세션 구분이 없어 "함께 읽힌 기사"의 경계를 직접 정의해야 함
  • 기사 수명이 하루 안팎이라 매 배치마다 새로 학습하고 30분 안에 결과를 내야 함

설계 결정

  • 로그 종류: 방문·클릭·파트너스 로그로 각각 추천풀을 만들어 검수. 클릭 로그가 방문 로그와 정분류율이 비슷하면서(25.6% vs 28.9%) 2.5배 빨라 채택
  • 세션 경계 41초: 클릭 간격에서 IQR 기준 이상치(1,255초 초과)를 제거한 중앙값. 길이 3 이상 시퀀스만 학습
  • 필터 시점: 오래된 기사를 학습 전에 빼지 않고 추천 단계에서 1일 이내 기사만 남겨 동시 클릭 신호를 보존
  • 입력 기간 1일: 3일이 정확도 0.26으로 조금 높지만 소요 시간이 3배라 30분 배치에 맞춰 1일 선택
  • gensim skip-gram 100차원, window 10. 이후 신고·삭제 콘텐츠 제외 로직을 추가해 유지보수
